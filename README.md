# 📦 Gerenciador de Estoque Simplificado em Python

Este é um projeto prático desenvolvido em Python para o gerenciamento básico de um estoque de produtos e preços, utilizando listas e estruturas de controle.

## 🚀 Funcionalidades

*   **Cadastro de Produtos:** Permite a inserção dinâmica de novos itens e seus respectivos valores.
*   **Remoção de Itens:** Remove de forma segura o último item adicionado ao estoque, garantindo que a lista não esteja vazia.
*   **Listagem Completa:** Exibe de forma formatada todos os produtos disponíveis e seus preços em Reais (R$).

## 🛠️ Tecnologias Utilizadas

*   **Python 3**
*   Estruturas de dados nativas (`listas`)
*   Iteradores e formatação de strings (`f-strings` e `zip`)

## 📖 Como Executar

1. Inicialize o estoque rodando a célula de criação das listas padrão.
2. Utilize a função de cadastro para adicionar novos produtos informando o nome e o preço via entrada do usuário (`input`).
3. Utilize a função de remoção para retirar o último item inserido e atualizar o inventário automaticamente.
